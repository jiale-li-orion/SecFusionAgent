# 事件库与资料库

适用：2026-10-15 已授权的显影与扩散界面迭代，尚待用户审阅。实现位于 `EventLibrary.tsx`、`MaterialLibrary.tsx` 与就近的 `library-explorers.css`。

事件库以可横向浏览的日期轴定位记录，再显影当前记录；同日记录通过编号按钮切换，不排列成事件列表。事件档案的概要接口只提供档案更新时间，因此概览明确标注“档案更新”；候选线索优先使用来源发布时间，否则标注系统发现时间。日期统一按 UTC 归组，未知日期独立保留。已建立档案的同一 candidate 不重复展示为候选。选择档案后按需读取真实演化历史，按 event_time 排列，缺失时使用 observed_at 并说明。概览日期不能解释为事件发生日期。

资料库使用独立 `GET /api/v1/intelligence/library`，不再复用首页 18 条流。公开可用留存资料的精确总数、类别/来源/细分主题数量均由服务端返回；过滤后的 `total` 与全库 `corpus_total` 分开。接口以 `as_of` 限制 revision 创建时间，并按最新 revision 时间与 document_id 排序，每页 48 份；URL 保留筛选、页码与快照，进入档案后返回仍可继续阅读。新资料等待新查询加入；权限与对象生命周期每次读取重新检查，不保证跨页期间撤权或归档不改变总数。

服务端仅返回库存范围内、来源明确公开、原始 artifact 全部明确公开且至少存在一份 artifact 的材料；未知权限、缺失证据、已拒收内容、旧错误页、首页导航页不计入总数。广域新闻源仍要求与受关注 Repo/ResearchWork 的有效关系。一次流式 SQL，每批 128 行，每份最多读取 6000 字符首段与摘要，不加载全文、不做逐文档 SQL。由于旧资料质量需要重验，统计会扫描紧凑候选投影，开销随资料数量线性增长。

显影主题地图展示全库细分主题，例如提示注入、越狱、运行时隔离、智能体记忆、检索增强、模型评测、身份权限、供应链、训练投毒、隐私泄漏、推理基础设施、漏洞利用、AI 治理、事件响应、智能体安全及其他。主题由标题与正文片段匹配，可交叉归类，主题数量不可相加当作资料总数。每页六个主题，可翻页筛选；类型、来源和文字检索在服务端覆盖全部可用资料。

阅读区仅对当前页最多 48 份资料进行确定性内容相似度聚类：英语词元、中文二元词段及少量明确双语短语构成特征；标题计两次，摘要计一次；TF-IDF 向量归一化后计算余弦相似度，以 0.12 阈值平均连接聚类。共享细分主题仅用于给已完成的簇命名，不决定成员。资料按 story_id 去重，无关联资料保留独立入口。该计算只用于阅读呈现，不持久化，不声称全库语义推断。方法说明收于可展开帮助。


情报频道保留推荐、关注、事件库、资料库。独立热点入口撤下；无对象选择的旧 `channel=hot` 深链重定向首页热点。已有漏洞/对象/证据深链继续可读；首页热点保持不变。

使用已存在的本地字体与 DevelopingField。原生按钮与 select 支持键盘操作、可见焦点；手机采用双列主题与单列阅读，时间轴横向滚动仅限轴内；减少动态效果时关闭内容过渡并静态显示显影画布。各数据源分别处理读取中、失败、重试与空态，不补造记录。

验证：`node scripts/test-library-presentation.mjs` 覆盖时间来源、时区归组、候选去重、内容主题匹配、无命中、资料去重和演化排序；同时运行 `npm run build` 与 `npm run lint`。

资料库扩展验证：`apps/application/tests/test_material_library.py` 与 `apps/api/tests/test_library_routes.py` 检查公开证据、精确总数、稳定分页、最新版本、筛选和证据定位；`node scripts/test-material-catalog.mjs` 检查 48 份聚类上限与细分主题命名。
