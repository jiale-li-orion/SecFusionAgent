# SecFusionAgent · 显影与扩散

当前实现已进入 `main`（2026-10-16）。以抽象颗粒显影/扩散为基础，按每页内容个性化部署。基础效果曾获用户认可；不把工程检查视为全部页面美术验收。

## 美术依据

观察、比对、辨认是安全研究的核心动作。采用颗粒沉积、抽象显影和局部扩散形成共同材质，避免玻璃光影、无意义的线束与扫描特效。版面使用开放阅读区、清晰字级和疏密变化，保留既有信息及操作顺序。

## 页面构成

采用颗粒沉积、边缘散落与扩散参数。禁止品牌/标题/状态字形纹理、声音波形、线圈或服务页虚构采样曲线；不以放大的字体轮廓代替抽象显影。

各页共用颗粒材质，通过沉积位置、宽厚比例、局部迁移、交互汇聚程度和显影起点形成不同构成。参数归 `developingProfiles.ts`；不把标题、状态、数量映射为装饰图像。

| 页面 | 抽象构成 |
| --- | --- |
| 问答 | 保留已恢复的三处颗粒沉积及原交互参数 |
| 发现 / 关注 | 分散散布 / 围绕内核聚拢 |
| 热点 / 事件 | 较密的集中沉积 / 斜向逐处展开 |
| 文献 / 对象阅读 | 薄层叠印 / 较厚的交叠层次 |
| 调查 | 分离的沉积逐步相互靠拢，聚焦时加强汇聚 |
| 任务 / 运行 | 错位交叠、缓慢迁移 |
| 技能 | 薄层围绕中间沉积累积，节奏更慢 |
| 服务观测 | 疏散分布、局部迁移；不冒充实际曲线 |
| 世界 | 分散成簇、横向延展；原关系画布独立 |
| 个人 / 偏好 | 内部较密、外缘疏松、聚焦向内收拢 |
| 登录 / 注册 | 两片材质相遇，中部保留细小沉积 |

页面形态是本轮实现，尚待用户实际审阅。真实数据由原有图表和正文呈现，装饰不表示进度、数量或可信度。

## 渲染与交互

`DevelopingField` 使用一个 WebGL 画布，`developingShader.ts` 负责固定颗粒、局部显影、扩散和矿物色叠印，不生成文字或图表纹理。聚焦收拢，输入触发短扩散，建议悬停改变沉积中心。

宽度上限 1200 像素，像素倍率上限 1.5；普通设备最高 30 帧、粗指针设备最高 24 帧。离屏与后台暂停，减少动态效果时静态呈现且交互立即更新。WebGL 不可用或上下文丢失时使用静态颗粒底纹。卸载释放 RAF、着色器、缓冲及监听。

## 旧组件统一

基础 Card 不再默认提供圆角边框和底板；Item 不再默认整行背景高亮。更新了世界材料标签、来源标签、运行概览分格、证据断言和原文套框、来源条目、覆盖维度、问答引用及审计折叠区。去掉内部链接的重复尾箭头；保留返回、发送、展开、分页和真实关系方向。界面英文内部术语转为可读名称，技术坐标仍可展开。

热点加载占位采用文章字行，个人关注词与统计区去掉标签底盒和分隔线。资料类型采用可换行的文字选择项，保留 Radix 键盘选择和焦点提示。档案已知字段和发布状态使用展示名称；来源正文与未知状态保留原值。

全站使用本地 Manrope / Noto Sans SC UI。元信息不低于 12px，普通说明 14–16px；不使用默认等宽字体表现产品字段。

## 验证边界

桌面与手机检查覆盖 18 个页面及子视图，另检查任务详情、证据抽屉、服务子标签和登录注册。验证构建、lint、CSS 所有权、文件规模与名称转换测试。问答交互只填入草稿，不发起收费模型调用。私人调查和历史会话没有新建数据，不宣称完成其真实生成流程。动效通过时间推进、聚焦、建议中心变化、减少动态效果及离屏暂停检查；静态截图仅检查构成。

本轮复核：14 个主要页面／频道、4 个对象视图、登录与注册均检查桌面和手机；确认显影渲染与横向布局。问答三个固定时间点的 GPU 像素与基础版本一致，14 种构成均在时间推进后改变。另验证分类键盘选择、热点加载完成及减少动态效果。
