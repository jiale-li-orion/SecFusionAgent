# Product artwork

`research-assistant.webp` belongs only to the empty Ask welcome state. `workspace-slides.webp` is a small services-section ornament. Both have real transparency, empty alternative text, fixed dimensions and no pointer events. Neither represents evidence, a source, a status, or an interactive control. They are static and respect the page's reduced-motion behavior.

The attempted `gpt-image-2.5-sunburst` high-quality API generation returned `model_not_found` from this machine's configured distributor channel on 2026-10-12. The selected production assets were therefore generated with the built-in imagegen service, inspected at page size, then encoded as transparent WebP. Their exact planned 2.5 prompts and the generated direction comparison are in [`design/image25`](../../design/image25/README.md). The first assistant variant and the optical instrument were rejected in visual review; the instrument is retained only in the design folder and is not loaded by the app.

The earlier generic `research-lens.webp` was removed because reusing the same abstract loop in Ask and Workspace obscured the separate roles of those spaces.
