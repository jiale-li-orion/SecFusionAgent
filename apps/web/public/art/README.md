# Product artwork

`investigation-dossier.svg` belongs only to the empty Ask welcome state. It shows layered paper, a page clip and colored tabs in place of the rejected eye and crystal motifs. `workspace-slides.webp` is a small services-section ornament. Both are transparent decorative assets with empty alternative text, fixed dimensions and no pointer events. Neither represents evidence, a source, a status, or an interactive control. They are static and respect the page's reduced-motion behavior.

The attempted `gpt-image-2.5-sunburst` high-quality API generation returned `model_not_found` from this machine's configured distributor channel on 2026-10-12. The earlier production ornaments were generated with the built-in imagegen service. The replacement dossier is an editable SVG because the service returned connection errors during this revision. The planned 2.5 prompts and initial direction comparison are in [`design/image25`](../../design/image25/README.md). The first assistant variant and optical instrument were rejected in visual review; neither is loaded by the app.

The earlier generic `research-lens.webp` was removed because reusing the same abstract loop in Ask and Workspace obscured the separate roles of those spaces.
